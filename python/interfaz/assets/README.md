# Logo ESPE

Coloca acá el logo institucional como `logo_espe.png` (fondo transparente
recomendado, mínimo ~300x300px) para que aparezca en el encabezado del
reporte PDF de participante (Vista Análisis → Exportar → "Generar reporte
PDF", ver `_generar_reporte_pdf()` en `app_investigador.py`).

Si el archivo no existe, el reporte se genera igual, solo que sin logo —
no es obligatorio.
